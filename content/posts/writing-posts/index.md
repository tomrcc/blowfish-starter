Each post is a folder inside `content/posts/`. The folder holds the post's text (`index.md`) and any images it uses.

## The featured image

Blowfish uses an image named `featured.jpg` (or `.png`, `.webp`) in the post's folder as the post's thumbnail, its hero image and its social sharing image. Replace the file to change it, or pick a different image in the post's **Featured image** field.

## Images in the text

Drop an image into the Content Editor and it's uploaded into the post's folder, so Blowfish can resize it for different screens:

![A green placeholder image](inline-example.jpg "Images in the post folder are resized automatically.")

## Formatting

You can use **bold**, *italic*, [links](https://blowfish.page/docs/) and `inline code`, plus:

1. Numbered lists
2. Bulleted lists
3. Tables and quotes

> Blockquotes are styled by the theme too.
