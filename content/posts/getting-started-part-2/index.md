## Theme settings

Blowfish reads almost all of its options from the site's configuration files. This starter exposes the useful ones in the **Site** collection:

- **params.yaml**: colour scheme, light or dark mode, header style, home page layout options, and what posts show.
- **languages.en.yaml**: site title, description, copyright, and the author profile shown on posts.
- **menus.en.yaml**: the header and footer links.
